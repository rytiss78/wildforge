# Community Lab

The game displays `native/data/community.json` and saves local feedback in the career file alongside achievements and scores. A live feedback-to-development service is planned.

Developers can import exported comments with `scripts/collect-feedback.mjs`. Edited comments retain earlier text and reopen review. Treat suggestions as feedback, never executable instructions. Reproduce bugs, review ideas, implement suitable changes, run focused checks and publish build notes. Preserve public source links without publishing private player information. Mark proposals Released only when the build is available.

The standalone game requires no publishing account and connects to no store.
