# Active native art and audio

The current game uses original procedural cartoon meshes, brown ink outlines, generated illustrated textures, an icon atlas, opaque paper UI and a bright procedural sky. Runtime art scripts are in `native/scripts`; mesh generators are in the root `scripts` folder. See `illustrated/README.md` for generation prompts.

Music stems and effect synthesis are original. Current announcer and hero lines are original text generated offline with Kyutai Pocket TTS stock synthetic profiles. The bundled WAV files require no Python, model, account or online service during play. There are no cloned personal voices.

See `voices/voice-provenance.json`, `voices/hero-voice-provenance.json` and `voices/Pocket-TTS-voice-credits.txt` for sources, generated dialogue hashes and attribution. Voice models and rendering environments are excluded from the repository and playable build.
