# Illustrated 3D prototype models

Authored by `scripts/build-style-models.py` as real GLB meshes with UVs and named articulated pivots. Materials reuse the existing approved paper, bark and stone textures. No source game imagery or third-party models are included.

Assets: Count Duck, Bottlebite, mint pistol, storybook tree and brass bullet. `model-manifest.json` records mesh/triangle/source-size totals. See `native/docs/style-lab.md` for status and limitations. This is the first visual review checkpoint; the full game conversion remains pending.
