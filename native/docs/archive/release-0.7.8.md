Crowds should feel much smoother, and enemies should spend their time chasing you instead of circling invisible obstacles.

- Fixed enemies avoiding the hero before they could attack.
- Fixed enemies treating walkable slopes as walls.
- Improved routes around scenery so crowds keep moving.
- Reduced repeated work in enemy movement, terrain and XP drops.
- Frozen enemies can no longer hurt you through contact.

The packaged build passed checks for all attack behaviours, crowd navigation and XP collection, plus a crowded run through all six biomes. Performance improved substantially on our test PC, but occasional hitches remain. This is still an alpha.

Download the Windows ZIP, extract the whole folder and launch **Wildforge.exe**. Your existing saves work with this update. No Steam account needed.
