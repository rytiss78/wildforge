# Wildforge 0.7.7 — standalone Windows alpha

Download the Windows ZIP, extract the entire folder and run `Wildforge.exe`. No installation, Steam account or purchase is needed.

- Four-player standalone co-op: nearby LAN party discovery and direct IP/hostname/VPN joining.
- Local achievements and scores; existing progress is preserved.
- Stronger enemies drop more XP; touching XP orbs merge into larger glowing drops.
- Improved crowd navigation and spawning while exploring.
- Removed Steam integration and old publishing tools.

Choose **Play with friends** → **Host Party**. Friends join before the host starts. Remote friends need a shared VPN or reachable public IP with UDP 29736 forwarded. There is no hosted relay or matchmaking service.

This is an unfinished development alpha. Packaged host/client checks passed for discovery, shared combat, party pauses and world travel. Public-internet router traversal, four separate physical PCs and all controller hardware combinations have not been verified. Community suggestions currently save locally; automatic online feedback sharing is planned.
