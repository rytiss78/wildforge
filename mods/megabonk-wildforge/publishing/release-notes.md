# Megabonk Wildforge Mod 0.4.0 — combat and feedback

- Wildforge weapons use source base damage and firing rates. The starting gun deals 15 damage and fires every 0.61 seconds before upgrades.
- Cards refresh equipped weapon stats. Tests compare real damage and cooldown before/after stacking and removal.
- Basic visible models for all 65 weapons, with low-poly gun fallback and original flower/turret models.
- Distinct procedural weapon/action sounds; recoil, growing/swaying flowers, turret aiming/tracers and expanding effect cues.
- Shift or right mouse: dash. R: deploy equipped turret. Ctrl in air: slam. On-screen controls and cooldown feedback.
- Turret-capacity cards now increase deployment capacity up to four; flowers and turrets use equipped weapon power.
- Descriptions state the actual stat, units and conditions instead of repeating a card title or showing confusing negative bonuses.
- Native attack dispatch and return pools support custom weapon identities.

Windows x64 Megabonk 1.0.69 with BepInEx 6 IL2CPP x64 build 6.0.738. Install the loader separately; extract the manual ZIP into the game folder. Uses a separate Wildforge save profile.

Development alpha: source projectile/status/boss parity and full-run balance remain in development. AI tools assisted development and generated portions of the original art.
